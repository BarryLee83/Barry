# 玩家上手指南

**中文** | [English](Player-Guide-EN.md)

这份指南面向**第一次使用**、不熟悉目录结构的玩家。照着做一遍，之后每次切换只需要点一个按钮。

> 如果你只想快速开始，可以看仓库根目录的 [README](../README.md)。这里把每一步、每个弹窗和容易踩的坑都写清楚了。

---

## 0. 开始之前：5 分钟检查清单

先确认下面几项，能避免 90% 的问题。

- [ ] 系统是 Windows 10 / 11 64 位。
- [ ] 已经安装 SCUM，并且能正常进游戏。
- [ ] 知道每个私服的**编号**（例如 `0509`、`6646`）。
- [ ] 知道每个私服的**启动器 exe** 在哪。
- [ ] 已经**完全退出**游戏和启动器。
- [ ] 已经手动备份 `Saved` 和 `~Mods`（见第 2 节）。
- [ ] 目标磁盘至少有 10 GB 空闲。
- [ ] 程序放在普通目录（例如 `D:\AI\SCUM-Switcher`），不是 `D:\Coding`。
- [ ] 杀毒软件没有阻止程序运行。

全部打勾后再继续。

---

## 1. 认识两个关键目录

SCUM 只认下面两个“当前位置”：

```text
%LocalAppData%\SCUM\Saved
<游戏目录>\SCUM\Content\Paks\~Mods
```

- `%LocalAppData%` 一般是 `C:\Users\你的用户名\AppData\Local`；
- `<游戏目录>` 是 Steam 库里的 `steamapps\common\SCUM`。

切换器会为每个服建立两个归档目录：

```text
%LocalAppData%\SCUM\Saved.0509
<游戏目录>\SCUM\Content\~Mods.0509
```

可以这样理解：

| 目录 | 作用 |
| --- | --- |
| `Saved` | 游戏现在正在读的存档 |
| `Saved.0509` | 0509 服的存档归档 |
| `Paks\~Mods` | 游戏现在正在读的 MOD |
| `~Mods.0509` | 0509 服的 MOD 归档 |

切换 = 把当前 `Saved` / `~Mods` 存回旧编号，再把新编号的归档放回当前位置。

## 2. 第一次使用前：手动备份

### 2.1 这份备份是干什么的

游戏同一时间只认两份数据：

- `%LocalAppData%\SCUM\Saved`：当前存档；
- `<游戏目录>\SCUM\Content\Paks\~Mods`：当前 MOD。

切换器做的事，就是把这两份换成目标服的。程序会自动把旧数据放进回收区、失败时回滚，但回收区只保留最近几份，而且还在原来的盘上。第一次用之前，自己把这两份各复制一份到**别的文件夹**，等于多上一道保险：

- 选错服、路径填错；
- 切换途中程序被关掉；
- 以后误删了某个服的归档目录；

都可以用这份备份复制回去，不用重新练号或重新下载 MOD。

> `D:\SCUM-Backup` 只是示例，**不是程序要求的目录**。程序不会读取、修改或删除它。你可以换成 `E:\SCUM备份`、移动硬盘等任何有空间的位置。

### 2.2 要备份哪些东西

| 现在的位置 | 复制到（示例） | 说明 |
| --- | --- | --- |
| `%LocalAppData%\SCUM\Saved` | `D:\SCUM-Backup\Saved` | 当前存档，必须备份 |
| `<游戏目录>\SCUM\Content\Paks\~Mods` | `D:\SCUM-Backup\~Mods` | 当前 MOD；没有这个文件夹就跳过 |
| `%LocalAppData%\SCUM\Saved.<编号>` | `D:\SCUM-Backup\Saved.<编号>` | 每个服的历史存档；有就备份 |
| `<游戏目录>\SCUM\Content\~Mods.<编号>` | `D:\SCUM-Backup\~Mods.<编号>` | 每个服的历史 MOD；有就备份 |

最后两行是切换器已经按服归档的数据。注意 `~Mods.<编号>` 在 `Content` 下，**不在 `Paks` 下**。

备份完成后，备份目录大概长这样：

```text
D:\SCUM-Backup\
├─ Saved\          ← 当前存档副本
│  ├─ SaveFiles\
│  └─ Config\
├─ ~Mods\          ← 当前 MOD 副本（原来有才有）
├─ Saved.0509\     ← 可选：0509 服的存档归档
└─ ~Mods.0509\     ← 可选：0509 服的 MOD 归档
```

### 2.3 操作步骤

1. **完全退出游戏、官方启动器和各服的私服启动器。** 打开任务管理器，确认没有下面这些进程：
   - `SCUM.exe`（游戏本体，最常见）
   - `SCUM_Launcher.exe`（官方启动器）
   - `SCUM-Win64-Shipping.exe` / `SCUM-Win64-Test.exe`（其他版本/测试版游戏进程）

   名字对不上时，在任务管理器里找图标是 SCUM、或路径在 SCUM 游戏目录下的进程，以及各服自己的启动器，一并结束。
2. 新建备份根目录，例如 `D:\SCUM-Backup`。只建这一层，不要先在里面建 `Saved` / `~Mods`。
3. 打开 `%LocalAppData%\SCUM`，复制整个 `Saved` 文件夹，粘贴到 `D:\SCUM-Backup`。
   结果应该是 `D:\SCUM-Backup\Saved`，里面直接有 `SaveFiles`、`Config`，而不是 `Saved\Saved`。
4. 打开 `<游戏目录>\SCUM\Content\Paks`，复制整个 `~Mods` 文件夹，粘贴到 `D:\SCUM-Backup`。
   如果本机没有 `~Mods`，跳过这一步。
5. 如果有 `Saved.<编号>` / `~Mods.<编号>`，按 2.2 的表分别复制过去。
6. 检查：`D:\SCUM-Backup\Saved\SaveFiles` 存在，就说明存档备份成功。

备份放在另一个磁盘更稳妥。确认切换器工作正常后，这份手动备份可以保留也可以删除。

### 2.4 出问题怎么用这份备份还原

如果切换后发现存档不对、MOD 不对，或者怀疑数据丢了：

1. 完全退出游戏和切换器。
2. 把当前的 `%LocalAppData%\SCUM\Saved` 改名为 `Saved.bad`，**先不要删除**。
3. 把备份里的 `D:\SCUM-Backup\Saved` 整个复制回 `%LocalAppData%\SCUM\`，名字保持 `Saved`。
4. MOD 同理：当前 `Paks\~Mods` 改名 `~Mods.bad`，把备份里的 `~Mods` 复制回 `Paks\`。
5. 启动游戏确认。确认没问题后，再删除 `Saved.bad` / `~Mods.bad`。

如果只是某个服的归档不对，也可以从 `Saved.<编号>` / `~Mods.<编号>` 或回收区找回，见第 8 节。

## 3. 第一次启动程序

1. 解压发布包到 `D:\AI\SCUM-Switcher`。
2. 双击 `SCUM-Switcher.exe`。
3. 如果 Windows 提示“已保护你的电脑”，点「更多信息」→「仍要运行」。
4. 首次启动会出现三步引导：
   - 确认游戏路径；
   - 添加服务器配置；
   - 选择目标并切换。

引导可以关闭，之后从右上角齿轮进入「设置」。

### 3.1 确认路径

点右上角齿轮 → 「路径」：

| 字段 | 应该指向 | 检查方法 |
| --- | --- | --- |
| SCUM 安装目录 | `...\steamapps\common\SCUM` | 里面有 `SCUM\Content\Paks` |
| SCUM 数据目录 | `%LocalAppData%\SCUM` | 里面有 `Saved` |

如果显示“路径无效”：

- 点「浏览」重新选择；
- 或点「自动检测」；
- 仍找不到时，手动在资源管理器地址栏输入 `%LocalAppData%\SCUM` 确认存在。

> 注意：安装目录选的是**包含 `SCUM` 子文件夹**的那一层，不是 `SCUM\Binaries\Win64`。

### 3.2 添加第一个服务器

点左侧「添加」，按下表填写：

| 字段 | 怎么填 |
| --- | --- |
| 名称 | 自己看得懂即可，例如 `0509 服` |
| 编号 | 该服的唯一编号，例如 `0509`。只能字母、数字、`_`、`-`，创建后不能改 |
| 启动器程序 | 该服的启动器 `.exe`。不要选 `.bat` / `.cmd` |
| 启动参数 | 如果启动器需要参数才进对应服，照抄；否则留空 |
| 工作目录 | 一般留空，默认用 exe 所在目录 |
| 命令行关键字 | 多个服共用同一个 exe 时才填；exe 不同就留空 |
| 此配置不使用 MOD | 该服没有 MOD 时打开 |

保存后，配置卡片会显示：

- `Saved.0509 存在` 或 `不存在`
- `~Mods.0509 存在` 或 `不存在`
- 启动器是否在运行

第一次添加时，归档目录通常还不存在，这是正常的。切换时程序会处理。

### 3.3 导入已有目录

如果磁盘上已经有 `Saved.0509`、`~Mods.0509`，程序首次启动会自动发现并提示导入。也可以：

- 点「添加」旁边的自动探测；
- 或手动添加同编号的配置。

导入只添加配置，不会移动文件。

### 3.4 指定“当前配置”

如果程序检测不到正在运行的启动器，切换前会要求你先选“当前配置”。

为什么需要？因为程序必须知道当前 `Saved` / `~Mods` 属于哪个编号，才能把它们存回正确的归档目录。

- 如果你刚从一个服退出来，选那个服；
- 如果不确定，先看 `Saved` 的修改时间和大小，或看游戏里的角色/服务器信息。

选错会导致当前进度被存进错误的编号目录。第一次用请特别确认。

## 4. 添加其余服务器

重复第 3.2 步，为每个服添加配置。

### 多个服共用一个启动器 exe

如果几个服的启动器是同一个文件，只是参数不同：

1. 「启动器程序」选同一个 exe；
2. 「启动参数」分别填写各自参数；
3. 「命令行关键字」填**进程命令行里稳定出现**的文本，例如 `-server 0509` 或 `0509`。

关键字的作用只是“识别正在运行的是哪个服”，不参与启动。填错会导致关不掉旧启动器或识别不到当前服，但不会破坏存档。

### 没有 MOD 的服

打开「此配置不使用 MOD」。切换到这个服时：

- 当前 `~Mods` 会存回旧编号；
- 不会创建新的 `~Mods`；
- 游戏以无 MOD 状态启动。

### 启动器需要管理员权限

如果启动器自己会弹 UAC，或者提示“访问被拒绝”：

- 关闭切换器；
- 右键 `SCUM-Switcher.exe` →「以管理员身份运行」；
- 再切换。

## 5. 第一次切换：建议先做一次“空跑”

第一次切换前，建议先切到一个**不重要**的服，确认流程正常。

1. 完全退出游戏和启动器。
2. 左侧选中目标服。
3. 看中间摘要：
   - 当前 → 目标；
   - 复制模式还是联接模式；
   - 目标存档/MOD 是否存在；
   - 大约需要多少空间。
4. 点「切换到此配置」。
5. 观察进度：
   - 检查；
   - 关闭游戏/启动器；
   - 保存当前存档；
   - 载入目标存档；
   - 保存当前 MOD；
   - 载入目标 MOD；
   - 校验；
   - 启动。
6. 切换完成后，进游戏确认：
   - 角色/服务器正确；
   - MOD 正常加载。

确认无误后，再在真实服之间切换。

### 切换时不要做的事

- 不要手动打开游戏或启动器；
- 不要手动移动 `Saved` / `~Mods`；
- 不要在复制过程中强制结束切换器；
- 不要在游戏运行时切换（程序会阻止或询问）。

## 6. 遇到弹窗怎么选

### 6.1 目标存档不存在

说明 `Saved.<目标编号>` 还没有。

| 选项 | 什么时候选 |
| --- | --- |
| 创建空存档 | 这个服要重新建角色 |
| 复制当前存档 | 想用当前进度作为这个服的起点 |
| 返回 | 还没想好，先不切 |

创建空存档后，进游戏会重新建角色；复制当前存档会得到一份当前进度的副本。

### 6.2 目标 MOD 目录不存在

说明 `~Mods.<目标编号>` 还没有。

处理：

1. 点「打开 Content 目录」；
2. 新建文件夹 `~Mods.<目标编号>`；
3. 把该服的 MOD 文件放进去；
4. 回到弹窗点「重试」。

如果这个服确实不用 MOD：

- 点「不使用 MOD 继续」；或
- 提前在配置里打开「此配置不使用 MOD」。

### 6.3 游戏正在运行

默认「先询问我」：

- 「关闭游戏并继续」：程序强制关闭游戏；
- 「返回」：自己关游戏后再切。

也可以在「设置 → 安全」改成「自动强制关闭」。**不要在没有保存的情况下强制关闭。**

### 6.4 启动器关不掉

可能原因：

- exe 路径配错；
- 多个服共用一个 exe，但关键字没填或填错；
- 启动器以管理员权限运行，切换器权限不够。

处理：

1. 手动关闭启动器；
2. 检查配置里的 exe 路径和关键字；
3. 必要时以管理员身份运行切换器；
4. 重新切换。

### 6.5 切换失败 / 中途退出

- 如果界面提示“已回滚”，说明文件已恢复到切换前，可以重新尝试。
- 如果程序崩溃或被强制结束，下次启动会提示「回滚」或「暂时忽略」：
  - 不确定时选「回滚」；
  - 回滚后再检查存档和 MOD。
- 如果回滚失败，日志会保留，下次启动继续提示；可以按日志手动恢复，或从回收区/手动备份找回。

## 7. 日常使用

每次切换只需要：

1. 退出游戏；
2. 打开切换器；
3. 选目标服；
4. 点「切换到此配置」；
5. 等程序自动启动。

其他设置一次配好就不需要再动。

## 8. 回收区和“每个服的备份”

### 回收区是什么

切换时，如果某个编号的归档目录已经存在，又要把 live 数据写回去，旧归档会先被移到：

```text
%LocalAppData%\SCUM\.switcher-trash
<游戏目录>\SCUM\Content\.switcher-trash
```

这样即使覆盖过程中出问题，也能从回收区找回旧版本。

### 回收区保留几份

「设置 → 安全 → 保留最近几份旧存档」控制数量，默认 5，最小 2。

注意：这是**整个回收区**保留最近 N 份，不是每个服各 N 份。旧的条目会被更新的条目挤掉。

### 每个服的长期备份在哪

在：

```text
%LocalAppData%\SCUM\Saved.<编号>
<游戏目录>\SCUM\Content\~Mods.<编号>
```

这两个目录才是每个服真正的“备份 + 工作副本”。只要不手动删除，它们会一直保留每个服的最新数据。

> 如果你希望回收区也按每个服保留，需要修改程序逻辑；当前版本保持“整个回收区最近 N 份”的策略。

## 9. 复制模式 vs 联接模式

「设置 → 通用 → 切换方式」。

| | 复制（默认） | 目录联接 |
| --- | --- | --- |
| 原理 | 真实复制文件 | 创建指向归档目录的链接 |
| 速度 | 取决于大小 | 几乎瞬间 |
| 兼容性 | 最好 | 少数备份/同步工具不识别 |
| 磁盘占用 | 归档 + live 各一份 | 只有归档一份 |
| 适合 | 第一次用、稳妥优先 | MOD 很大、频繁切换 |

第一次用建议保持**复制**。确认一切正常后，再尝试联接。

联接模式下：

- `Saved` 和 `~Mods` 是链接，不是真实目录；
- 不要手动删除链接指向的目标；
- 某些备份工具可能只备份链接本身，不备份内容，需要确认。

## 10. 附加工具

### 管理员指令

左侧「管理员指令」：

- 按分类浏览；
- 搜索指令；
- 点「复制」；
- 回游戏按 `T` 打开聊天，粘贴，回车。

不同服务器/插件版本可能不同，以游戏内 `#` 列表为准。

### 地图与坐标

左侧「地图与坐标」：

1. 导入地图图片（可截图游戏内 M 键地图）；
2. 用两个已知点校准：分别输入两点的像素坐标和世界坐标；
3. 点击地图取点；
4. 复制 `#Teleport X Y Z`。

校准是线性映射，官方等距地图较准；自制非等距地图会有偏差。

### MOD 检查

左侧「MOD 检查」：

- 查看当前 `~Mods` 的文件数、总大小、各顶层条目占用；
- 发现同名 `.pak` 冲突；
- 停用/启用条目：
  - 停用移动到 `Paks\~Mods.disabled`，不会删除；
  - `.pak` 的 `.sig` 会一起移动；
  - 重新启用时一起恢复。

## 11. 出问题先看哪里

| 现象 | 先检查 |
| --- | --- |
| 切换按钮是灰的 | 路径是否有效、是否已选目标、是否正在切换 |
| 提示游戏在运行 | 任务管理器结束所有 SCUM 进程（`SCUM.exe` / `SCUM_Launcher.exe` / `SCUM-Win64-Shipping.exe` / `SCUM-Win64-Test.exe`）和各服启动器，或让程序强制关闭 |
| 提示目标 MOD 不存在 | `Content\~Mods.<编号>` 是否存在；是否该开「不使用 MOD」 |
| 提示目标存档不存在 | 选择创建空存档/复制当前存档 |
| 提示空间不足 | 清理磁盘，或改用联接模式 |
| 启动器没被关闭 | exe 路径、命令行关键字、管理员权限 |
| 切换后没启动游戏 | 启动器路径/参数/权限；看日志和警告 |
| 存档好像不对 | 检查当前配置是否选对；从 `Saved.<编号>` 或回收区找回 |
| 程序打不开/闪退 | 是否被杀软拦截；换普通目录；看 `%APPDATA%\SCUM-Switcher\logs` |

日志位置：

```text
%APPDATA%\SCUM-Switcher\logs\app-YYYY-MM-DD.log
```

也可以在「设置 → 关于 → 打开日志目录」直接打开。

## 12. 安全卸载

1. 关闭切换器；
2. 删除程序目录（例如 `D:\AI\SCUM-Switcher`）；
3. 可选：删除 `%APPDATA%\SCUM-Switcher`（配置、日志、历史）；
4. 游戏存档和 `Saved.<编号>` / `~Mods.<编号>` 不会被删除。

如果只想重置配置，删除 `%APPDATA%\SCUM-Switcher\config.json` 即可；下次启动会重新引导。删除前建议先备份整个 `%APPDATA%\SCUM-Switcher`。

## 13. 最后提醒

- **第一次用先手动备份。**
